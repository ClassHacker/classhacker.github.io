# Terminal Portfolio

Angular-powered terminal themed portfolio for Ajay Dayma.

🌐 GitHub Pages Link: [https://classhacker.github.io/](https://classhacker.github.io/)

## Commands

- `npm start` - run the local Angular dev server
- `npm run build` - create the production build in `docs/`
- `npm run deploy` - alias for production build (GitHub Pages serves from `main/docs`)

## GitHub Pages setup

For a user site repository (`classhacker.github.io`), configure **Settings → Pages** to deploy from:

- **Branch:** `main`
- **Folder:** `/docs`

Commit and push changes after running `npm run build`.
